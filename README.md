# poker-lineup-legal

Page publique de politique de confidentialité de Poker Lineup (une seule page statique, sans framework).
Les stores (Apple, Google) exigent son adresse. Cible : `https://poker-lineup.com/privacy`.

- **Aperçu local** : `python3 -m http.server 4180 --bind 127.0.0.1` dans ce dossier, puis http://127.0.0.1:4180/ (aucun port ouvert dans ufw).
- **Publication** : GitHub Pages (dépôt public contenant seulement ce dossier) + enregistrements DNS dans hPanel. **Pas encore faite**, en attente de validation de Vincent.
- **À garder vrai** : le texte décrit ce que fait l'app. Le relire à chaque changement de données collectées (paiements RevenueCat, export, analyses, SMTP).
- Brouillon non relu par un juriste.
